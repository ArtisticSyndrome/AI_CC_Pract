# AI Practicals

Collection of artificial intelligence practice programs and reference material.

## Contents

| File | Description |
| --- | --- |
| `BFS_DFS_Recurse.py` | Breadth-first search and recursive depth-first search on a sample graph. |
| `2_A_Star.py` | A* search on a predefined weighted graph. |
| `2_2_A_Star.py` | Interactive A* search that accepts graph, heuristic, start, and goal input. |
| `04_n_queens_backtracking.py` | N-Queens solver using classic backtracking. |
| `05_n_queens_branch_and_bound.py` | N-Queens solver using branch and bound sets for columns and diagonals. |
| `colourgraph.py` | Graph coloring using backtracking. |
| `Greedy_SelectionSort.py` | Selection sort implementation. |
| `MedicalExpertSystem.py` | Rule-based symptom checker. |
| `bankcusbot.py` | Simple banking chatbot using regex and NLTK utilities. |
| `AIprac.ipynb` | Notebook for AI practical work. |
| `CCP1 (1).pdf`, `P3.pdf`, `P4 (1).pdf` | Reference PDFs. |

## Requirements

Most scripts use only Python standard library modules. The banking chatbot requires NLTK:

```bash
pip install nltk
```

## Usage

Run any script with Python:

```bash
python BFS_DFS_Recurse.py
python 2_A_Star.py
python 04_n_queens_backtracking.py
```

For interactive scripts, follow the terminal prompts:

```bash
python 2_2_A_Star.py
python MedicalExpertSystem.py
python bankcusbot.py
```

## Notes

These programs are intended for learning and demonstration. The medical expert system and banking chatbot are simple rule-based examples, not production systems.
